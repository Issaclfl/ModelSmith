# 常见坑清单（来自真实求解事故，每条都有事故现场）

写代码前过一遍此清单；出 bug 时按此排查。

## 物理建模

| 坑 | 事故 | 防御 |
|----|------|------|
| Sellmeier/Cauchy 系数未验证值域 | 折射率算出 n≈1.0（正确 ~2.55），SiC 厚度差 3 倍 | 任何色散模型先在 3 个已知波数点对照文献值再使用 |
| 效率/损失系数硬编码为常数（eta_sb=1.0） | 阴影遮挡不计算，效率虚高 21%，与参考值偏差全部由此 | 效率必须由模型计算得出；搜索/评审前 AST 扫描拦截 |
| 平行光假设替代锥形光束 | 截断效率偏差 ~20% | 太阳角半径 4.65mrad 的模糊盘模型 |
| 量纲/单位混用 | 波数 cm⁻¹ 与波长 μm 混淆；km 与 m 同句混用 | 结果同时打印数值+单位；换算链打印中间值 |

## 干涉测厚（红外光谱法，2025B 实战）

| 坑 | 事故 | 防御 |
|----|------|------|
| 频率-厚度公式倒置 | 相位斜率 f=2nd·cosθ₁（cycles/cm⁻¹）误写成倒数，厚度算出 266 km | 条纹相位=2π·(2nd·cosθ₁)·ν，故 **d = f/(2n·cosθ₁)**；量纲自检：μm 级外延层 → f 在 10⁻³ cycles/cm⁻¹ 量级 |
| FFT 全局 argmax 选到低频包络尾 | 条纹频率选成频带下沿，厚度给假值 | 用突增峰检测（find_peaks+prominence）列前 3 候选人工核对，勿用全局 argmax；低频拖尾会永远赢 |
| 去基线窗口吃掉真条纹峰 | savgol 窗口 301 ≈ 0.76×条纹周期（采样点计），真峰被压制，双角度失配 20% | 去基线窗口必须远小于条纹周期（采样点计）；不确定就只去均值 |
| 双角度厚度不一致仍各自报告 | 10°/15° 偏差 25.7% 未裁决就交卷 | **同片晶圆厚度必须一致（硬约束）**：偏差 >5% 即方法有错；用第二方法（零填充 FFT+抛物线插值）交叉裁决 |
| FFT 候选峰呈整数比被忽略 | Si 谱候选 1×/2×/3× 谐波列 = 多光束干涉的频域证据，误判"无多光束" | FFT 候选呈整数比 → 多光束特征（问题3 判据）；单峰 → 双光束适用 |
| 评审（AI 评委）未提供题目原文 | 评委只评"像不像好论文"，无法判断切题度/数值合理性 | 深度评审必喂题目原文：核对切题度、逻辑覆盖、数值合理性 |

## 数据驱动

| 坑 | 事故 | 防御 |
|----|------|------|
| 裸回归弹性为正（违反需求定律） | 辣椒类 b=+1.017，季节混杂伪相关 | 控制月份/星期哑变量；升级 lnP+lnC 联合规格；加单品固定效应 |
| 收益口径割裂 | Q3 收益 > Q2 全集收益（逻辑不可能） | 统一口径：售出×价格 − 补货×成本，售出=min(需求,(1−λ)·补货) |
| 需求右截断 | 销量=需求被库存截断，预测偏低 | 缺货记录还原真实需求（数据采集建议） |

## 工程

| 坑 | 事故 | 防御 |
|----|------|------|
| 优化算法种群/迭代过小 | 种群5×迭代2，几分钟"跑完"结果无意义 | 种群≥50/迭代≥100（最低20/30需注释理由）；必须打印每代日志 |
| 前端 API 地址烤入 localhost | 远程用户浏览器调自己的 localhost，全站 API 假死 | 静态导出走相对路径，禁止 NEXT_PUBLIC_API_BASE=localhost |
| 服务器容器内 npm build | Next.js 构建需 ~2GB，2C2G 服务器 OOM | FastAPI 直接托管前端静态产物，跳过前端容器 |
| 容器重启丢任务 | 下载报 task not found（任务表在内存） | 任务注册表持久化到磁盘，启动时恢复 |
| PDF 编译缺 Typst/中文字体 | 论文下载失败/中文全是方块 | pip install typst + apt fonts-noto-cjk（Dockerfile 已内置） |

## 结论稳健性（2025 风电实战）

| 坑 | 事故 | 防御 |
|----|------|------|
| 披露残差却不计算残差对结论的杀伤半径 | 论文如实披露问题3 内层优化有 2% 深度残差，但没意识到该残差恰好击穿"35 台同时优于 36 台"的核心推荐——修复后"同时优于"不再成立 | 任何优劣排序结论：优势边际 > 依赖链最大已披露残差才可成立；边际 < 残差带必须降级表述（"在误差带内不可分"），并把受影响结论逐条重审 |

## 文本生产

| 坑 | 事故 | 防御 |
|----|------|------|
| 摘要误植其他题目内容 | A题摘要混入C题"问题4"段落 | 交付前逐段核对题目数量与内容对应 |
| 摘要报账体（只有结果没有理由） | 风电篇摘要句1/句2塌陷：报"年发电量 1115.4 GWh"却不说用什么模型、约束值多少、为何淘汰其他候选；对照 FAST 篇"准则+推理+结果"一句话闭环被判国一级 | 摘要每问一段走黄金三句式（方法句→约束决策句→结果句）；约束只写"塑造答案的"和"淘汰候选的"（带具体数值），每段 1-2 条；写完按 WRITING_STYLE 3.4 硬性自查逐项过 |
| 句式搬运外部范文 | 与命题人论文句式近似 | 借鉴思想必须改写为自述表达；外部文献只引真实查阅的 |
| 引用官方评阅文档 | 有答案反推之嫌 | 参考文献只列题面自带或真实查阅的公开文献 |
