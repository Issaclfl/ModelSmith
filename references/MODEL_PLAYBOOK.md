# 建模套路手册（按题型，来自四道已解真题）

每类题型给出：核心模型、已验证的算法骨架、已踩平的坑。范例脚本见 examples/。

## 使用规则：三差异规则（应用任何范例前强制）

**应用任何范例前，必须先列出本题与范例的 3 个物理差异**（研究对象 / 几何与尺度 /
边界条件 / 数据结构 / 目标量纲，任一方面均可）。列不出 3 个 = 还没理解题目，不配用范例。

差异清单决定三条路：
1. **差异可参数化**（对象变了、机理没变）→ 复制范例改参数与数据接口
2. **差异触及核心机理**（守恒关系/判定条件/目标函数结构不同）→ 只借算法骨架，公式逐个重推
3. **列不出差异或差异致命** → 放弃范例，进 DISCIPLINE 三.5 安全模式

差异清单本身写进论文（问题的提出 / 模型建立）——它就是评委要看的"为什么这么做"，
也是"借鉴范例"与"套模板"在答辩时的分界线。

## 一、干涉测量类（范例：2025B SiC 外延层厚度）

**核心模型**：双光束干涉。光程差 OPD = 2·n·d·cosθ，极值条件 OPD = m/ν。
厚度由条纹间距反解：d = 1/(2·n·cosθ·Δν)。

**已验证要点**：
- 折射率模型先验证：在 3~5 个已知波数处对照文献值（nSiC≈2.53~2.55，nSi≈3.42）
- 极值检测要多种子：Savitzky-Golay 平滑（窗口 21/51/101 对比）+ prominence 阈值扫描
- 单位链：波数 cm⁻¹ ↔ 波长 μm（λ=10⁴/ν），厚度 cm→μm→nm 逐级换算并打印

**坑**：Sellmeier 系数不验证值域会算出 n≈1.0，厚度差 3 倍；不同文献的
"参考答案"差异巨大（7.3~10.2 μm），根因就是折射率取值与色散处理不同——
论文里要声明自己的口径。

## 二、几何投影类（范例：2023A 定日镜场）

**核心模型**：五因子光学效率 η = ηcos·ηsb·ηat·ηtrunc·ηref。
- ηcos = √((1+s·r)/2)（角平分线法向）
- ηsb：投影法——邻镜角点沿太阳光线/反射光线投影到目标镜平面，
  Sutherland-Hodgman 裁剪 + 多邻镜**并集**面积（栅格化，避免重复累加）
- ηtrunc：太阳模糊盘——镜面网格点的反射光斑（半径 d·tan4.65mrad 圆盘）
  与集热器等效盘的透镜交集面积比，网格均值

**布局优化骨架**：六边形蜂窝密排（最近邻=宽+5，行距 Δ√3/2）→ 候选生成；
两级评估（300 镜×12 时刻代理粗筛 → 前3名全量 60 时点终评）。

**坑**：ηsb=1.0 硬编码（效率虚高 21%）；等距变化下最优解取"总功率最大"
而非"单位面积功率最大"，取舍逻辑要在论文里显式交代。

## 三、几何解析类（范例：2023B 多波束测线）

**核心模型**：斜坡覆盖宽度 W = D·sinθ·cosα / [cos(θ/2+α)·cos(θ/2−α)]；
重叠率 η = 1 − d/W。

**骨架**：自适应间距递推（d = W_next·(1−η)，用**下一条/窄侧**宽度保证
窄处也满足重叠率下界）；真实地形时**分块变间距**（块内代表水深取分位数
q，q=0 零漏测极端、q=1 零超限极端，q∈(0,1) 权衡）——q 是漏测-超限
权衡的连续旋钮，本身就是灵敏度分析素材。

**坑**：间距用当前线宽会让窄处重叠率低于下限；浑水地形（沿线水深变化
10 倍）零漏测与零超限不可兼得——构造方案谱系如实呈现权衡是正解。

## 四、数据驱动类（范例：2023C 蔬菜定价）

**核心模型**：需求识别 ln Q = a + b·lnP + c·lnC + 月份/星期哑变量（FE
面板更佳：加单品固定效应消除"高销量单品恰好低价"的结构性混杂）。

**骨架**：878k 行流水 → 品类/单品日级聚合（加权价）→ 弹性回归 →
利润最大化网格搜索（搜索上界约束在历史定价经验域 P99，防外推）→
补货量 = 预测需求/(1−损耗率)。

**坑**：裸回归弹性为正（季节混杂）——必须控制月份/星期；仍有内生性
（成本驱动定价）→ 升级 lnP+lnC 联合规格；仍识别失败的品类**诚实回退**
近期加成率中位数。组合优化注意收益口径统一（售出×价格 − 补货×成本，
售出 = min(需求, (1−λ)·补货)）。
